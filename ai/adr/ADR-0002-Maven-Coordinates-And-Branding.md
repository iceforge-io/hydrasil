# ADR-0002: Maven Coordinates and Ice Forge Branding

## Status
Accepted

## Context
Ice Forge projects use professionalized coordinates and branding aligned to `iceforge.io`.

## Decision
Use:

- Maven groupId: `org.iceforge.hydrasil`
- Java package root: `org.iceforge.hydrasil`
- Repo name: `hydrasil`
- Version: `0.1.0-SNAPSHOT`

## Consequences
The project is aligned with the broader Ice Forge ecosystem and can later publish Maven artifacts cleanly.
