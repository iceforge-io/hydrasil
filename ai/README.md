# Hydrasil AI Design Space

This directory contains the persistent project memory for AI-assisted design and implementation.

## Directory Map

- `adr/` — Architecture Decision Records
- `dqr/` — Design Question Records
- `existing-architecture/` — source system notes
- `new-design/` — target architecture notes
- `plan/` — delivery and POC plans
- `standards/` — coding, testing, Git, and PR standards
- `brain/` — TPN/BDA-style ideation
